### 문제와 기대 결과

#### 사용 주체와 상황

Walnut의 정상 일봉 처리 번들은 로컬 JSON 응답과 manifest를 해석하고,
Rosemary API로 PostgreSQL에 저장 및 조회한 뒤 독립 비교와 사용자 QA를 수행한다.
Walnut은 Rosemary 안에 연결된 Flax의 로컬 Cargo 소스를 소비한다.

원래 요청은 `data/todo/20261010-walnut-parsing-dependencies.md`에 보관되어 있으며 Git에서 제외된다.
요청 파일이 없는 다른 체크아웃에서도 이번 공급의 기준을 확인할 수 있도록 요구사항을 아래에 기록한다.

#### 해결할 문제와 개발 목적

현재 Flax의 레지스트리에는 serde 1.0.229가 있으나 serde_json과 chrono는 없다.
Walnut이 JSON 해석과 날짜 변환에 사용할 두 라이브러리와 필요한 전이 소스를 추가한다.
기존 소스 보관 및 오프라인 소비 경로를 사용하여 재현 가능한 공급 결과를 제공한다.

#### 기대 결과

Walnut이 자신의 Cargo.toml과 Cargo.lock으로 두 라이브러리를 선언하고,
Rust/Cargo 1.89.0에서 Flax 소스를 이용해 `--locked --offline`으로 빌드할 수 있다.
Flax는 정확한 버전과 기능, 출처, 라이선스, 체크섬 및 기본 소비 검증 결과를 반환한다.

### 범위와 요구사항

#### 포함 범위

- serde_json과 chrono의 고정 버전 및 필요한 전이, 빌드 의존성 공급.
- 원본 배포 소스와 라이선스 및 파일별 체크섬 보존, 레지스트리 목록 갱신.
- 독립 소비 검증 구성의 Cargo.toml, Cargo.lock 및 실제 활성 기능 기록.
- JSON 해석과 출력, 날짜 해석 및 시각 변환의 기본 소비 가능성 검증.
- 기존 PostgreSQL/gRPC 공급과 소비 경로의 변경 영향 확인 및 필요한 회귀 검사.
- 소비 리비전, 재현 명령, 실행 로그 위치와 미실행 범위를 포함한 반환 자료 정리.
- Flax 요청 기록에 진행 상태와 실제 완료 결과 반영.

#### 제외 범위

- 이번 작업에서 제외: 모든 upstream 예제, 개발 의존성, 선택 기능과 플랫폼의 완전한 공급 및 실행 검증.
  이번 소비 구성의 의존성 해결에 필요한 소스와 현 환경의 소비 검증을 대상으로 한다.
- 이번 작업에서 제외: chrono의 로컬 시간대 탐색 및 clock 기능.
  명시적 offset의 시각 해석과 날짜 변환에는 요청되지 않았다.
- 대상 범위 밖: Walnut 제품 파서와 저장 연결부 구현, 전체 482행의 파싱/저장/조회 및 DB QA.
  Walnut 세션에서 수행한다.
- 대상 범위 밖: Rosemary/Walnut의 소스와 고정 서브모듈 리비전 변경.
  필요한 리비전 갱신은 해당 프로젝트에 인계한다.
- 대상 범위 밖: 전역 Cargo 설정 변경, Walnut으로의 별도 라이브러리 소스 복사,
  Rosemary 드라이버의 with-serde_json/with-chrono 활성화.

| ID | 요구사항 |
| --- | --- |

| F2 | chrono로 YYYYMMDD와 달력 날짜를 해석하고, 명시적 offset을 가진 RFC3339 수집 시각을 UTC microseconds로 변환한다. 필요한 최소 기능만 사용한다. |
| F3 | 현재 JSON 포맷의 문자열 날짜와 정수 필드를 해석하고 결과를 JSON으로 출력할 수 있음을 확인한다. 문자열 정수는 부동소수점을 거치지 않고 u64로 정확히 해석한다. |
| F4 | `2026-10-02T09:09:35.581009+09:00`과 `2026-10-02T00:09:35.581009Z`가 같은 UTC microseconds로 변환되며, `20261001`을 실제 달력 날짜로 해석할 수 있음을 확인한다. |
| F5 | 고정 버전, 선언 기능과 실제 활성 기능, 잠금 파일, 출처/라이선스/체크섬, 재현 명령 및 실제 검증 결과를 소비자가 확인할 수 있게 제공한다. |

#### 지켜야 할 제약

버전은 기존 조합의 실제 소비 빌드로 확인하여 고정한다.
기존 공급 소스를 임의 교체하거나 Rust 도구 체인을 올리지 않는다.
레지스트리 반입과 검증 구성은 Flax 안에서 수행하고 타 프로젝트 제품 코드는 변경하지 않는다.

원본 분류와 소스 보관 규약, 캐시와 로컬 할 일의 Git 제외 규칙을 유지한다.
필요한 전이 소스와 대상별 의존성을 확인하되, 모든 선택 기능을 공급하는 요구로 확대하지 않는다.

#### 미확인 전제

- 공급할 두 라이브러리의 정확한 버전, MSRV, 기존 serde와의 호환성 및 전이 의존성은 아직 확인하지 않았다.
- 요청된 기능만 활성화한 최종 Cargo 의존성 그래프와 실제 소비 빌드는 아직 검증하지 않았다.
- 새 소스 추가가 기존 소비 구성에 미치는 실제 영향과 이번 회귀 검사의 실행 결과는 아직 확보하지 않았다.
